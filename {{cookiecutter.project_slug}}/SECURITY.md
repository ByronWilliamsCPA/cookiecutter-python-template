## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Use GitHub Security Advisories to report privately:
<https://github.com/{{ cookiecutter.github_org_or_user }}/{{ cookiecutter.github_repo_name }}/security/advisories/new>

Or email: {{ cookiecutter.security_email }}

## Response Timeline

- Acknowledgement: within 48 hours
- Initial assessment: within 5 business days
- Resolution target: 30 days for critical, 90 days for others
